# TeamGlowing

TeamGlowing 是一个以“小队联机协作”为核心的 `Fabric 1.21.x` 模组，当前目标兼容范围为：

- Minecraft `1.21 ~ 1.21.11`
- Fabric Loader `0.16.14+`
- Java `21`

它的核心玩法是把“组队、找人、标点、据点、传送、重生”串成一整套联机体验。

## 模组玩法概览

装上模组后，你和队友可以获得以下能力：

- 创建并管理小队
- 看到同队玩家的专属发光
- 在经验条上方看到队友和旗帜的定位栏
- 用中键共享方块、掉落物、实体标记
- 用旗帜建立小队据点和普通标记点
- 用指南针配合磁石进行据点传送
- 死亡后选择在床边重生，或在小队据点附近重生
- 在聊天栏、Tab 栏、社交界面中获得更清晰的小队信息展示

## 快速上手

### 1. 创建小队

普通玩家不需要 OP 权限，直接使用：

```mcfunction
/tg create <小队名> [颜色]
```

示例：

```mcfunction
/tg create 远征队 蓝色
/tg create 红石组 #55AAFF
```

说明：

- 小队名最长 5 个字
- 创建时可以直接指定颜色
- 指令别名支持 `/teamglow` 和 `/tg`

### 2. 邀请队友

```mcfunction
/tg invite <玩家名>
```

被邀请玩家可以：

- 点击聊天栏中的 `[接受]` / `[拒绝]`
- 或手动输入：

```mcfunction
/tg accept
/tg reject
```

### 3. 管理小队

队长可进行以下管理：

```mcfunction
/tg rename <新队名>
/tg color <颜色>
/tg admin add <玩家名>
/tg admin remove <玩家名>
```

管理员可以帮助队长邀请新玩家加入。

### 4. 查询与退出

```mcfunction
/tg info
/tg leave
```

## 组队后的主要玩法

### 同队发光

- 同队玩家会看到彼此的发光效果
- 非同队玩家不会看到不该显示的发光
- 发光由服务端按视角同步，避免全局乱亮

### 聊天栏和 Tab 栏识别

- 聊天栏会显示玩家的小队识别信息
- Tab 栏会显示小队名、颜色和菱形图标
- 社交界面会增加 `+` 邀请按钮，方便直接邀请未入队玩家

### 定位栏 HUD

在经验条上方会显示一条定位栏，用来追踪：

- 队友
- 小队旗帜
- 普通旗帜标记

定位栏特点：

- 会根据视角实时转动
- 支持跨维度坐标换算
- 按住 `Tab` 可显示玩家名或旗帜名
- 旗帜使用原版地图的旗帜图标
- 小队旗帜会带特殊视觉标识，和普通旗帜区分开

## 世界标记玩法

### 中键共享标记

你可以使用鼠标中键标记并共享给队友：

- 方块
- 掉落物
- 实体

这些标记会在世界中渲染，而不是只显示在 HUD 上。

用途示例：

- 标记矿点
- 标记掉落战利品
- 标记目标生物
- 标记路线终点

## 旗帜玩法

旗帜是 TeamGlowing 里非常重要的一套玩法。

### 小队旗帜

小队旗帜代表整个小队的据点。

绑定方式：

- 手持 `追溯指针`
- 潜行
- 右键旗帜

效果：

- 将当前旗帜设为小队旗帜
- 定位栏中会用特殊标识显示
- 可作为“小队据点重生”的目标

说明：

- 整个世界只允许存在一个小队旗帜
- 原小队旗帜被破坏后会自动清除记录

### 普通旗帜标记

普通旗帜是给小队共享的一组普通定位点。

绑定方式：

- 手持普通 `指南针`
- 潜行
- 右键旗帜

效果：

- 把当前旗帜加入本小队共享的普通旗帜集合
- 在定位栏中显示原版地图旗帜图标
- 如果旗帜被铁砧重命名，按住 `Tab` 时会显示该名字

说明：

- 未重命名旗帜会显示默认名，而不是翻译键
- 旗帜被破坏后会自动清除记录

## 旗帜隐藏玩法

### 隐藏全部小队旗帜

- 手持 `追溯指针`
- 潜行
- 右键空气或普通方块

效果：

- 切换“小队旗帜”在定位栏中的显示/隐藏

### 隐藏全部普通旗帜

- 手持普通 `指南针`
- 潜行
- 右键空气或普通方块

效果：

- 切换“全部普通旗帜”在定位栏中的显示/隐藏

### 单独隐藏某个旗帜

- 不潜行
- 直接右键某个已记录旗帜

效果：

- 只切换当前这一个旗帜的显示/隐藏

## 磁石传送玩法

如果你想把普通旗帜做成“传送点”，可以这样搭建：

1. 在旗帜下方放置一个 `磁石`
2. 用普通指南针绑定这个磁石
3. 让该旗帜成为普通旗帜标记

之后：

- 手持这把已绑定磁石的普通指南针
- 潜行
- 右键空气或普通方块

若匹配到对应旗帜，就会启动传送。

传送规则：

- 传送前等待 3 秒
- 使用 Bossbar 显示进度
- 等待期间必须保持静止
- 发生位移则传送取消
- 成功后传送到旗帜附近安全位置

## 小队据点重生

当你死亡后，死亡界面会提供额外的重生选择：

- 原版重生
  - 仍按床 / 重生锚 / 默认出生点处理
- 小队据点重生
  - 重生后传送到小队旗帜附近

这意味着你可以把小队旗帜当作真正的共享据点来使用。

适合的玩法包括：

- 团队基地
- 远征营地
- 地下矿区集结点
- 地狱或末地前线据点

## 指令总表

```mcfunction
/tg create <小队名> [颜色]
/tg rename <新队名>
/tg color <颜色>
/tg invite <玩家名>
/tg admin add <玩家名>
/tg admin remove <玩家名>
/tg accept
/tg reject
/tg leave
/tg info
```

也支持完整前缀：

```mcfunction
/teamglow ...
```

## 数据保存

小队与旗帜等数据会保存到服务端运行目录中的：

```text
teamglowing-parties.json
```

保存内容包括：

- 小队信息
- 成员与管理员
- 小队颜色
- 小队旗帜
- 普通旗帜标记
- 邀请状态

## 构建与运行

在项目根目录执行：

构建：

```powershell
.\gradlew.bat build
```

运行客户端：

```powershell
.\gradlew.bat runClient
```

运行服务端：

```powershell
.\gradlew.bat runServer
```

构建产物通常位于：

```text
build/libs/
```

## 说明

- 当前工程使用 Fabric Loom 构建
- 模组主要逻辑以服务端为主，客户端负责渲染、HUD 和界面
- 小队身份目前仍基于玩家名，大小写不敏感
- 本地化当前提供 `zh_cn` 与 `en_us`
